# Project Risk AI v1.0.0

Інтелектуальна система оцінювання ризику зриву термінів IT-проєктів на основі машинного навчання.

## Функціонал

- Оцінка ризику проєкту (Низький / Середній / Високий) на основі 8 параметрів
- Алгоритм: Random Forest Classifier (точність ~77%)
- Візуалізація результатів: pie chart та bar chart важливості факторів
- Генерація Excel звіту з результатами оцінки
- Налаштування теми інтерфейсу та параметрів моделі
- Логування всіх дій у logs/app.log
- Конфігурація через зовнішній файл config.json

## Запуск

```bash
# Активувати віртуальне середовище
source venv/Scripts/activate  # Windows Git Bash

# Запустити програму
python main.py
```

## Стек

- Python 3.12
- customtkinter — GUI
- scikit-learn — ML модель
- matplotlib — графіки
- openpyxl — Excel звіти
